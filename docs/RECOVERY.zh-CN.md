# 清理与故障恢复

停止请求 ≠ 后端清理确认 ≠ 真实定位恢复。三者分开显示。

Android 后端将停止调度、退出启用过的 FLP mock mode、移除本项目建立的测试源，再等独立读回。不能移除未归属本项目的配置；异常退出未必能执行 finally。

iOS 后端在同一开发会话调用 clear，再关闭连接。断线、桌面强停或手机进程挂起后不能确认执行结果时转 UNKNOWN。重连先提供清理重试，不自动继续轨迹。当前后端尚未实现，本文件是验收要求。

状态机只接受清理回执后产生的新鲜恢复证据；来源信息缺失不视为 false，非模拟标志本身也不是充分证据。无法验证真实位置时显示等待/需要人工确认，不显示已恢复。

故障诊断顺序：停止其他定位工具 → 检查权限/配对/连接 → 明确重试清理 → 独立系统读取 → 检查微信缓存与具体功能。不得默认刷机、清空微信数据或修改用户 VPN。

任何需要真实位置的导航、出行或紧急操作前，应退出模拟并独立核对。工具不得承诺固定时间必然恢复。
