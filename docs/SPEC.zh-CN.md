# LocVela 产品规格

版本：0.1；基线日期：2026-10-25。此文是研发规格，不是已实现能力声明。源于项目方案，当前实现状态以 README、ROADMAP 和实际测试结果为准。

## 1. 产品与首发设备

LocVela（位航）是本地优先的跨平台位置模拟与轨迹控制工具。首发验收对象固定为三星 S25 / Android 16、iPhone 16 / iOS 18.4.1，微信逐项测试；系统构建、固件地区、GMS 状态和微信完整构建不能猜测。

Android 首先走原生无 Root 模拟位置。iPhone 首先走桌面辅助开发服务会话，本机独立模式作为单独里程碑。不把尾插、越狱、三星解锁或服务器部署作为首版条件。

## 2. 功能范围

P0：固定坐标、启停、权限/配对检查、原生定位后端、独立系统读回、微信分项测试、清理与失败诊断、中英交互。P1：地图、搜索、收藏、GPX、多点路线、速度、停留、循环、暂停、Android 可选摇杆、报告导出。P2：iPhone 本机模式、确认授权后的局域网控制、更多设备适配。

暂停保持当前模拟点；停止才释放模拟通道。无强制账号、会员、广告、默认云同步或公网控制服务。

## 3. 微信验收范围

聊天发送位置的默认中心与接收端卡片；实时共享的接收端持续轨迹；朋友圈附近地点与发布标签；小程序单次定位、连续定位和地图选点；微信内网页 Geolocation；实际可见的附近服务与视频位置入口。

手工搜索地点不证明设备定位改变。POI 名称与原始坐标分开。小程序接口权限不足、入口不可见或账号不具备资格时标记不可测，不算通过。开发工具结果不能代替真机。

设备位置后端不负责公网 IP、账号资料地区、运营商侧记录或服务器位置判定；普通系统模拟也不承诺只影响微信。不能以“全部支持”替代分项证据。

## 4. 交互与产品形态

手机：地图 + 底部控制面板，显示目标点、会话状态、最近读回、开始/暂停/停止。桌面：设备栏 + 地图 + 状态诊断。高级参数进入二级界面；不支持的参数禁用并解释，不能放置无效开关。

明确区分“已下发”“系统已验证”“某微信功能已验证”。独立读回不能来自软件自己保存的目标坐标；版本改变后旧结果只能是历史证据。

## 5. 平台路线

Android 使用 LocationManager 测试定位源，并按检测结果选择允许的路径。GMS 可用时以单独适配器使用 FLP 模拟模式。Framework fused 与 Google FLP 不是同一接口。位置事件正确填写时间、单调时钟、精度等字段。使用可见界面启动的定位前台服务与通知停止，不靠关闭省电规则代替服务实现。[S1-S3]

iOS 桌面依次处理发现、信任配对、开发者模式、开发支持组件、开发通道、持久会话、写入、清理及恢复观察。依赖必须固定版本；不得每秒启动 CLI。断线时不能保证清理命令已送达。[S4]

iOS 本机客户端通过设备配对材料与本地开发连接访问定位服务；签名、后台挂起、锁屏、网络及 VPN 冲突独立验收。拥有后台权限不等于永久运行。App Store、通用 IPA 安装及自动系统降级均不作承诺。[S5-S8]

## 6. 架构与数据

Rust 负责可验证的坐标/时间线/状态机；Android Kotlin、iOS Swift 负责各自权限、生命周期与后端；桌面计划 Tauri。初期 iOS 协议适配候选为 pymobiledevice3，后期可评估 idevice。保留替换能力，不为统一语言重写整套协议。

内部统一带类型的 WGS-84。GCJ-02 等转换在地图边界完成并保留来源及转换器版本；当前核心不实现转换，绝不能将 GCJ-02 数据直接标成 WGS-84。[S9]

确定性轨迹用相对时间与明确采样，不加入规避识别的随机抖动。相同输入得到相同输出。坐标计算与真实设备下发时间分别记录。导入限制大小、点数、坐标范围及时间顺序；拒绝 NaN/Infinity 和不安全 XML。

## 7. 状态与恢复

IDLE → PREPARING → READY → RUNNING ↔ PAUSED → STOPPING → CLEARED_WAITING_REAL_FIX → IDLE。活动状态可转 UNKNOWN 或 RECOVERY_REQUIRED。

停止请求、后端确认、新鲜独立读回和可信基线一致性分别记录；缺一项不得推定后续步骤。位置来源标记缺失不等于真实。断连转未知，重连优先清理旧会话，用户明确启动后才能重新模拟。室内信号和系统缓存可能延迟真实定位，不承诺固定恢复秒数。

同一 LocVela 设备会话只允许一个写入者，但普通客户端不能强制阻止其他工具。检测竞争线索后告警，不隐瞒异常。

## 8. 地图与外部服务

底图、搜索、路由与位置后端解耦。地图失效时坐标输入与已存场景仍可使用。服务 API Key、配额、缓存规则和署名需要逐一核验；不使用公共演示端点冒充免费生产服务。“本地优先”不代表联网搜索从不向服务商发送请求。

## 9. 隐私与分发

默认不存完整真实轨迹；配对文件、UDID、密钥、签名材料及精确个人位置不提交到公共仓库。凭据用平台安全存储，报告使用匿名设备别名与脱敏证据 ID。下载和依赖固定版本，发布带校验值、构建信息和第三方声明。

原创采用 AGPL-3.0-only，引用部分保留原许可并登记。源码公开不等于签名、地图服务或设备安装权限自动具备。

## 10. 验收与交付门槛

核心自动化测试、平台编译、真机验收三者分开。每个结果绑定设备/系统构建/微信版本及渠道/工具后端版本/功能/场景/时间和证据。

建议测试目标：受控固定点读回误差不超过 10 米；无原始坐标的地图观察不能伪造米级精度；实时共享 30 分钟含锁屏 10 分钟；启停 20 次；拔线、休眠、强停、权限撤销、网络切换全部测试。它们是目标，不是已取得的成绩。耗电和发热与同设备基线比较，不预报成功率。

阶段：M0 基线和可行性 → M1 Android 闭环 → M2 iPhone 桌面闭环 → M3 微信兼容与日常功能 → M4 iPhone 独立模式 → M5 发布工程。任何未通过的微信功能在发布说明中明确标注。
